Reflection

This project felt slightly challenging only because I was trying to figure out the right css properties to use. One property in particular was the border-style. I didn't realize I had to set that in order to see a border. When it came to understanding padding and margins, the easiest way for me to understand how these work is by thinking about the box model. Every element contains padding within it's "box". At the same time, every element contains margins that exiat outside of their "box". There is no best practice on when to use which, instead, it's better to think about when it is appropriate to use the correct element. There were definitely some moments when the code broke. I generally ran into this issue when I would copy and past the nav over to this page. This would happen because the links were related to the home pages paths, which did not make sense for this page. I hope there is a way to create a global nav component through the main css folder.
