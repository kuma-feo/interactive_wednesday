My Reflection

This assignment was tricky. I got very close to getting the site looking almost entierly like the image reference I was given. The trickiest part was making sure I was thinking conceptually about the box model. I got so confused when it came to creating the right amount of padding. I also got confused with the organge body color and the light blue wrapper colors. I feel like there was likely better ways to do what I did, but I at least got close to what was being asked.

This assignment taught me a lot about CSS. One prominent thing was how creatie you can be about organizing css classes and styles. I found myself repeating quite a few things and thinking about how I could simplify this moving forward. Because I got so deep into the project, I ended up just leaving the code as is and think about how i can improve on the next assignment.

If I had more time, I would have placed the images on the bottom to be inline instead of stacked. I ran out of patience and time to make this happen.
